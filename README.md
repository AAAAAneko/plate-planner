# Plate Planner

A simple browser-based plate layout planner for 6-well, 24-well, 48-well, and 96-well experiments.

## Features

- Supports 6, 24, 48, and 96-well plate layouts
- Custom experimental conditions with colors, treatments, time points, and notes
- Click-and-drag well selection
- Quick fill by selected wells, rows, columns, or repeated wells
- Export as CSV, protocol CSV, PNG, PDF, or JSON
- Import saved JSON designs

## Usage

Open `index.html` in a browser, or use the GitHub Pages link if available.

## Files

- `index.html`
- `styles.css`
- `script.js`

# 孔板布局规划工具

一个用于实验孔板布局设计的网页小工具，支持 6 孔板、24 孔板、48 孔板和 96 孔板。

## 功能

- 支持 6、24、48、96 孔板布局
- 可自定义实验条件、颜色、处理方式、时间点和备注
- 支持点击和拖拽选择孔位
- 支持按选中孔、整行、整列或连续重复孔快速填充
- 支持导出 CSV、方案 CSV、PNG、PDF 或 JSON
- 支持导入已保存的 JSON 设计文件

## 使用方法

直接用浏览器打开 `index.html`，或使用 GitHub Pages 网页链接。

## 文件

- `index.html`
- `styles.css`
- `script.js`
